# Tetration vs Graham

"Can a Tetration Ball Deal Graham's Number Damage in 60 Seconds?" This is the companion to Fibonacci vs
Googol, using the same futuristic arena.

- The giant ball has **Graham's number (G)** HP. The small ball hits at a **steady pace** and never speeds up.
- Hit *n* deals **3↑↑n**, which is 3 tetrated n times (a tower of n threes): 3, 27, 7,625,597,484,987, then
  3↑↑4, a number with **3,638,334,640,025 digits**, and on from there.
- These numbers can't be written out, so the panel shows them as power towers of 10s (3↑↑n ≈ a tower of
  n−3 tens topped with 3.64×10¹²). Each hit adds one gold "3" tile to the tower.
- The answer is **NO**. Just reaching 3↑↑↑3, which is smaller than g₁ (the first of the 64 layers that build
  Graham's number), takes 7,625,597,484,987 hits. At about 1.6 hits a second that's around 150,000 years.
  The end screen works this out from the hits in that run.
- The HP ring never moves: G minus anything you could deal here is still G, as far as any number you could
  write down can tell.

screen's shape. The run is exactly 60 seconds, plus the "NO." screen. **RUN IT AGAIN** appears 5 seconds
later, so trim it off.
